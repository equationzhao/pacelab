# PaceLab

乳酸阶梯测试的计时、记录与分析工具。

[在线使用](https://equationzhao.github.io/pacelab/)

- 填写姓名、性别、年龄和 FTP，按测试目的生成阶梯参数，支持手动调整。
- 选择侧重 LT1、同时观察 LT1 / LT2 或快速获得总体曲线，配置采样模式。
- 开始第一级前可记录静息乳酸，也可直接跳过；静息值单独保存，并随 JSON、CSV 和报告导出。
- 记录乳酸、心率、RPE、样本质量和备注。
- 通过蓝牙连接功率计（Cycling Power）、心率带（Heart Rate）及 ERG 骑行台（FTMS），查看实时功率、心率、踏频。
- ERG 骑行台按运动阶段自动设置目标瓦数；单人采血间隔和手动暂停时暂停骑行台，下一运动阶段恢复，测试结束时停止。
- 开始测试后按秒记录活动，暂停时停止记录；导出 FIT，包含设备读数、阶段分圈、静息乳酸及每级乳酸和 RPE。
- 每级最后 30 秒自动展示乳酸值和 RPE 大号录入区，输入后自动保存；单人模式下持续显示至采样间隔结束。
- 计时结束自动进入下一阶段，末级采样完成后自动结束测试；阶段记录支持随时补录和修改。
- 比较单拐点、双拐点与平滑曲线模型，估计 LT1 / LT2，显示拟合线和定位区间。
- 保存历史测试、复制协议、对比曲线。
- 导入导出 JSON、导出 CSV、打印报告。

打开 `dist/PaceLab_运动表现测试工作台.html` 即可使用。数据保存在当前浏览器，JSON 文件可用于备份和迁移。

蓝牙连接请使用支持 Web Bluetooth 的电脑端 Chrome / Edge 或 Android Chrome，访问在线 HTTPS 版本或 localhost。Safari / iOS 浏览器不提供此连接能力，仍可手动记录测试。仅支持上述标准蓝牙服务，不支持 ANT+ 或设备私有协议。ERG 骑行台必须提供 FTMS 目标功率控制、功率范围及控制回执；仅广播 FTMS 读数的设备不能从此入口连接。设备若正被其他应用占用，需先在该应用中断开。

连接 ERG 骑行台时先申请控制权。开始测试前检查剩余各级目标是否符合设备的最小／最大瓦数及功率步长，不支持的目标会阻止开始，不会自动改写测试协议。运动阶段设置目标功率并启动；双人连续采样保持运动，切级时直接更新瓦数。单人采血间隔与手动暂停发送 FTMS Pause，结束和主动断开连接前发送 Stop。暂停／停止后的实际阻力行为由骑行台实现决定，不使用 0 W 目标代替暂停。

界面区分“正在设置”和“已确认目标”，只有收到设备成功回执才显示确认，实际达到目标的过程可查看实时功率。控制指令串行发送，快速切级或暂停会替换尚未执行的旧目标。控制失败、外部停止、目标被外部修改、控制权丢失或断线时自动暂停测试；响应超时后需先在设备端确认停止负载，再断开并重连。继续测试会重新申请所需的控制权。ERG 使用骑行台自身的功率反馈，独立功率计用于记录，不提供 PowerMatch。

开始前分别点击设备的“连接”，在浏览器中选择设备。独立功率计和心率带优先，FTMS 数据作为备用。设备断开或读数超过 5 秒未更新时，相应数据留空；目标功率另存，不当作实测功率。测试时请保持页面在前台，避免系统休眠；浏览器在后台可能延迟计时和采集，恢复时不会补造设备读数。刷新或关闭页面会暂停活动并尝试停止骑行台，但浏览器退出或连接中断时不能保证停止指令送达，需在设备端确认负载已停止。重新连接设备并点击“继续”后恢复记录。切换测试时当前活动自动暂停。

点击“导出 FIT”可下载当前活动，进行中也可导出快照。每级包含运动段与单人采样间隔，保存为一个 lap；暂停时间从 FIT 的 timer time 中扣除。乳酸与 RPE 使用 FIT developer fields，既保存在对应 lap，也附在采样时刻的 record。实时输入保留原采样时间，结束后首次补录则归到该级运动结束时刻，另存实际录入时间；修改后重新导出会使用最新数值。静息乳酸及其时间保存在 session 的 developer fields。第三方平台可能不展示这些自定义字段，但字段保留在原始 FIT 文件中。

JSON 备份包含完整设备记录，可导入后重新导出 FIT；单次导入上限 32 MB。活动记录占用当前浏览器的本地存储空间，建议每次测试结束后同时下载 FIT 和 JSON，清理不再需要的历史测试。CSV 和报告仍展示阶段手动记录，实时设备流在 JSON / FIT 中。

开发时运行 `python3 -m http.server 5173`，访问 `http://localhost:5173`。运行 `python3 build.py` 更新单文件版本。

分析版本为 `three-phase-turnpoints-v3`。LT1 为低负荷基线后的首次上升转折；LT2 按三阶段模型估计中负荷段进入更快积累段的转折。使用实际功率与乳酸，不使用固定 2/4 mmol/L、基线加值或 FTP 代替阈值。

LT1 已确认时，优先在其附近至最后有效读数的中高负荷分区定位 LT2；分区至少 5 个实际观测，须通过逐点删除和 LT1 起点变化的敏感性检查。LT1 未确认时，第二节点仍可由三阶段模型独立检验。

三阶段模型至少需要 7 个有效读数，各段至少 2 个观测。比较三段与单拐点、直线、二次曲线的 BIC，改善至少 2 且斜率结构成立才继续检查。逐个删除样本，分别检验两个结点的信号、条件模型改善和位置移动；LT1 不稳定时仍可保留 LT2。平滑指数模型能拟合曲线，不再作为否定 LT2 的依据。

LT1 还可由独立的基线后指数增长或单拐点模型确定，至少需要 6 个有效读数。已有三阶段支持时，对基线起点独立复拟合；只有更贴近观测的稳定结果才用于细化 LT1，避免高负荷尾部把起点推晚。指数起点处的斜率变化须在局部采样间隔内达到可分辨幅度。单独使用单拐点时仍比较无起点的平滑对照。指数曲线的增长尺度不作为 LT2。

曲线拟合与阈值定位分别记录，CSV/JSON 包含 `analysis_model`、LT1/LT2 各自的模型及版本。阴影为包围逐点删除结点的实际功率样本范围，不是统计置信区间。证据不足的结果留空。

[技术参数和实测复跑报告](validation/model-v3-2026-10-19/report.md)包含独立 NumPy/SciPy 数值核对。该核对验证计算一致性，尚不代表生理阈值定位已获得独立验证；阶梯测试估计也不等同于恒功率测试验证的 MLSS。

“排除”样本不参与拟合；“可疑”样本仍参与并显示质量记录。重复或未递增的功率不会给出拐点。原始历史记录保持原样，打开时使用当前算法重新计算；CSV、JSON 和打印报告包含分析方法与当前估计。

方法参考：[分段回归识别乳酸转折](https://pmc.ncbi.nlm.nih.gov/articles/PMC7739369/)；[基线后指数增长模型（Nolte 等，预印本）](https://doi.org/10.51224/SRXIV.136)。应用对指数模型增加了独立增长幅度参数，并加入模型比较与逐点删除检查，不是原作者代码的直接复现，也未将其参数作为独立 LT1/LT2 真值。

协议生成器按 FTP 的 45% 预填起始功率，取整至最近的 5 W。三个测试目的分别使用 10–15 W / 7 min / 10 级、15–25 W / 6 min / 10 级、25–30 W / 4 min / 9 级；递增功率分别按 FTP 的 1/18、7.5%、10% 取整到 5 W，再限制在对应范围内。FTP 为 270 W 时，LT1 方案为 120 W 起步、每级增加 15 W、每级 7 min、共 10 级，最高 255 W，阶梯时间 70 min。总时间仅含运动阶梯，不含热身和单人采样间隔。

姓名、性别和年龄用于记录；协议参数由 FTP 和测试目的生成。个人资料随每次测试独立保存，兼容没有个人资料的旧记录。测试目的不作为拐点拟合的输入。

验证计算：`node --test test/turnpoints.test.cjs`。

验证蓝牙协议解析、ERG 控制、记录时间及 FIT 编码：`node --test test/devices.test.cjs test/erg.test.cjs test/recording.test.cjs test/fit.test.cjs`。额外使用 Garmin 官方解码器验证：先运行 `npm install --prefix /tmp/pacelab-fit-check @garmin/fitsdk --no-save --no-package-lock`，再运行 `FIT_SDK_PATH=/tmp/pacelab-fit-check/node_modules/@garmin/fitsdk/src/index.js node --test test/fit.test.cjs`。运行时仍无外部依赖。

浏览器流程验证脚本为 `test/browser-devices.cjs`，需先启动 localhost:5173 服务并安装 Playwright；通过 `NODE_PATH` 指向 Playwright 所在的 node_modules，`FIT_SDK_PATH` 指向上述 SDK，再运行 `node test/browser-devices.cjs`。可用 `CHROME_PATH` 指定 Chrome 路径、`PACELAB_URL` 指定本地服务地址。脚本使用模拟蓝牙设备，覆盖连接、通知、掉线、暂停恢复、导出与导入、移动端及单文件版本；真实硬件仍需实测。
